# Palacharla Swamy — Portfolio

A responsive, cinematic portfolio personalized from Swamy’s resume. Dark charcoal, warm gold, editorial typography, animated portrait, project narratives and accessible interactions. Built with HTML, CSS and JavaScript; no installation or compilation required.

## Preview

Open `index.html` in a browser, or run `npm start` and visit http://localhost:4173. Google Fonts are optional; system fonts work offline. Email copying works best on localhost or HTTPS.

## Publish on GitHub Pages

1. Create a GitHub repository. For a profile website, name it `YOUR-USERNAME.github.io`; a repository named `portfolio` also works.
2. Upload **the contents of this folder** to the root of the repository, including `assets` and `.nojekyll`.
3. In repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**. Save.
4. GitHub will show the website URL once deployment finishes. All asset paths are relative, so both profile and project Pages are supported.

Alternatively, upload this folder to any static host. No API keys or backend required.

## Customize

- `index.html`: all resume content, email, phone and project descriptions.
- `styles.css`: colors, typography, responsive layouts and portrait motion.
- `script.js`: mobile navigation, portrait tilt, reveals, scroll progress and copy email.
- `assets/swamy-palacharla.jpg`: professional portrait.
- `assets/Swamy-Palacharla-Resume.pdf`: downloadable resume.

The resume does not contain usable GitHub or LinkedIn profile URLs, so no guessed social links are published. Add your exact URLs to the contact links when available. Project case studies describe work in the supplied resume; client data and project source code are not included. Visualizations are illustrative and labeled accordingly. The Perpetua date is preserved as December 2025 because no end date is provided.

Your supplied resume PDF contains your phone number and email. Both are included in this portfolio for professional contact. Review the PDF before making the repository public if you want to change what you share.

## Design reference

Inspired by the cinematic direction of https://github.com/lohithadamisetti123/cinematic-portfolio (dark palette, warm accents, large type and motion). This is an original implementation; no source code, video, or personal content was copied from that repository. The moving avatar uses your actual photograph with float and pointer tilt effects; it is not a generated talking video. Motion respects the visitor’s reduced-motion preference.
